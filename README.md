# AI Vision Deck — End-to-End AI Automation Architecture (Commercial Print)

An anonymized portfolio piece: a complete AI-first IT vision for a **mid-size commercial print & packaging manufacturer** (~100–150 people, three production buildings), designed as an interview deliverable and published here with all company-identifying details removed.

## What this is

A sovereign, hybrid AI fabric for a manufacturing operation — on-prem open-weight inference as the default workhorse, a task-typed routing gateway for frontier-model overflow, an evaluated decision layer, and edge vision on the production floor. Everything is proposed, phased, and measurable: no science projects.

## Architecture at a glance

- **Tier 1** — open-weight models, self-hosted on company hardware, handling anything touching sensitive data (customer artwork, job tickets)
- **Tier 2** — frontier reasoning models behind a task-typed gateway for hard-reasoning overflow
- **Decision layer** — evaluated routing/scoring/guardrail gates between rules-based systems and people
- **Four concrete agents** mapped to floor workflows, each with human-in-the-loop and rollback
- **OT-segmented, MIS-integrated** — vendor AI kept at the machine layer, learning orchestrated across vendors
